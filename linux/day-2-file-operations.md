# Day 2 - Linux File Operations and Permissions

## Commands Practised

- `mkdir`: Create a directory.
- `touch`: Create an empty file.
- `ls -l`: List files and permissions.
- `cp`: Copy a file.
- `mv`: Rename or move a file.
- `rm`: Delete a file.
- `chmod`: Change file permissions.

## File Permissions

- `r` = Read
- `w` = Write
- `x` = Execute

### chmod 644
Owner can read and write. Group and others can read.

### chmod 600
Only the owner can read and write.

## Safety Note
Check filenames before using `rm`, because deleted files
usually do not go to a recycle bin.
